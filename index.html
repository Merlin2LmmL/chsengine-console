Chat

Define function handleCommand(cmd, args, ctx). It's called for every opponent chat line starting with the prefix above (cmd lowercased, args the rest split on whitespace). Return a string to send back as a chat reply, or null/nothing to stay silent — it can also be async. ctx gives you { gameId, color, opponent, movesPlayed, chess, log }, where chess is the live chess.js instance for that game (read it, don't mutate it). This runs as plain JS in your own browser tab with no sandboxing — only paste code you trust.
